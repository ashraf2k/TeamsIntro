# Teams for Teachers · تيمز للمعلمين

A quick, bilingual (English / العربية) guide that helps teachers get started with Microsoft Teams:
scheduling a class, starting it, and controlling students' microphones, cameras, chat, screen sharing,
recording, breakout rooms and ending the meeting.

دليل سريع ثنائي اللغة يساعد المعلمين على البدء في استخدام مايكروسوفت تيمز: جدولة الحصة وبدؤها
والتحكم في ميكروفونات الطلاب وكاميراتهم والدردشة ومشاركة الشاشة والتسجيل وغرف المجموعات وإنهاء الاجتماع.

## Features
- One-click English ⇄ Arabic switch (full right-to-left layout for Arabic)
- 10 short step-by-step topics + checklist & FAQ
- Search, progress tracking ("Mark as done"), light/dark mode, mobile friendly, printable
- A single static `index.html` — no build step, no dependencies

## Publish with GitHub Pages
1. Push these files to the `main` branch.
2. In the repo go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After a minute the site is live at **https://ashraf2k.github.io/TeamsIntro/**

## Editing the content
All text lives in the `TOPICS` and `UI` objects inside `index.html`. Each topic has an `en` and an `ar` version.
